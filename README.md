# Ô Mineiro — Site e cardápio digital

Site institucional desenvolvido para o restaurante Ô Mineiro, com cardápio digital e página de localização. Projeto freelancer com foco em navegação responsiva e apresentação dos produtos.

[Acessar o site](https://dev-juanvictor.github.io/o-mineiro-mobile-2pt/)

## Páginas

- **Início:** apresentação do restaurante.
- **Cardápio:** consulta aos produtos.
- **Localização:** informações para encontrar o restaurante.

## Tecnologias

HTML e CSS.

## Estrutura

| Arquivo ou pasta | Conteúdo |
| --- | --- |
| `index.html` | Página inicial |
| `cardapio.html` | Cardápio digital |
| `localizacao.html` | Localização |
| `style.css`, `cardapio.css`, `localizacao.css`, `theme.css` | Estilos e tema |
| `assets/` | Recursos visuais |

## Como visualizar localmente

Baixe o repositório pelo menu **Code → Download ZIP**, extraia os arquivos e abra `index.html` no navegador. Mantenha a estrutura de pastas para carregar os estilos e imagens.
